# Pinned dependencies for reproducible builds.
#
# WHY PINNED: an unpinned `pandas>=2.0.0` was free to resolve to pandas 3.x in
# CI, which carries breaking changes and could silently corrupt data or crash
# the recorder. Every version below is locked to a known-good, mutually
# compatible release (verified to resolve together). The compiled core
# (numpy / pandas / scipy) is intentionally held to the conservative,
# ubiquitous, battle-tested line rather than the bleeding edge.
#
# To upgrade deliberately: bump a pin, run the test suite (pytest) + the
# data-health workflow, and only then commit the new pin.

# --- compiled core (held conservative on purpose) ---

pandas==2.2.3
scipy==1.13.1
